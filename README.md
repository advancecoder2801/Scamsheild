# 🛡️ ScamShield

A web-based scam detection and awareness platform designed to
help users identify suspicious messages and stay safe from
online scams.

## ✨ Features

- 🔍 Suspicious message detection
- 🚨 Scam risk alerts
- 🛡️ Online safety tips
- 📱 User-friendly interface
- 📊 Scam awareness information

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
